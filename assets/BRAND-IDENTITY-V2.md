# OctoLens Brand Identity V2

## Brand idea

**The discovery instrument for GitHub.**

OctoLens helps developers see the repository landscape around the project they
are viewing. The identity combines two ideas:

- **The lens** — inspection, clarity, and better technical judgment.
- **The constellation** — related repositories, alternatives, and paths worth
  discovering.

## Messaging hierarchy

| Role | Copy |
|---|---|
| Product name | **OctoLens** |
| Primary promise | **See beyond the repository.** |
| Product descriptor | **Private discovery for GitHub.** |
| Proof line | **Relevant alternatives · Local-first · No tracking** |

## Visual language

### Logo behavior

- Keep the capitalized spelling **OctoLens**.
- Preserve the magnifying-lens silhouette and one discovery spark.
- Use repository nodes, code glyphs, and orbital paths only as supporting
  elements—not inside small app icons.
- Keep the emblem readable at 16 px by removing constellation detail at small
  sizes.

### Color system

| Token | Hex | Use |
|---|---|---|
| Obsidian | `#070D17` | Hero backgrounds and premium launch surfaces |
| GitHub Dark | `#0D1117` | Core product background |
| Slate | `#161B22` | Elevated surfaces and controls |
| Lens Blue | `#4493F8` | Primary actions and wordmark accent |
| Spark Blue | `#79C0FF` | Highlights, discovery nodes, and focus states |
| Signal Cyan | `#42C7FF` | Rare high-energy accents |
| Cloud White | `#F0F6FC` | Primary text |
| Mist | `#8B949E` | Supporting text |

Blue should communicate active discovery. Avoid purple gradients and rainbow
accents; they weaken the GitHub-native, engineering-focused position.

### Typography

- **Display:** Inter Tight SemiBold, Geist SemiBold, or a similar geometric
  sans-serif with compact proportions.
- **Interface/body:** Inter, Geist Sans, or the system UI stack.
- **Technical labels:** Geist Mono, IBM Plex Mono, or the system monospace
  stack.
- Use sentence case. Avoid all-caps marketing headlines.

### Image direction

- Dark, precise, and optically layered.
- Use controlled blue light rather than broad gradients.
- Repository graphs should feel curated and sparse, never like a generic
  network visualization.
- Prefer negative space and one clear focal idea over feature-pill grids.

## Voice

OctoLens sounds observant, concise, and technically credible.

- Say **find relevant alternatives**, not **AI-powered discovery magic**.
- Say **local-first**, not **we value your privacy** without proof.
- Explain what data stays local and what is sent to GitHub.
- Prefer calm evidence over hype, urgency, or surveillance language.
