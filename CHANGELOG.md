# Changelog

All notable user-facing changes to OctoLens are documented here.

## [1.2.2] - 2026-08-12

### Added

- Added a plain-language privacy disclosure and policy links inside the
  extension popup.
- Added the public privacy policy and Chrome Web Store listing source of truth.
- Added compliant Chrome Web Store screenshots and promotional artwork.

### Changed

- Prepared the extension package and metadata for Chrome Web Store review.

## [1.2.1] - 2026-08-11

### Added

- Added local backup and restore for bookmarks, history, notes, interests, and
  feature settings while excluding tokens and API cache data.
- Added the OctoLens V2 brand identity, banner, and improved README guidance.
