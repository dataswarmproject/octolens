          Features

          Your interests

          Built from likes, hides, clicks, bookmarks and "more of…" choices. All local.

          GitHub token (optional)

          Provides higher API limits. Use a fine-grained token with the least privilege needed for public repositories. Stored only on this device. Create one

          Backup & restore

          Move your bookmarks, history, notes, interests and feature settings between browsers. Backups never include your GitHub token or API cache. Import replaces this local data after confirmation.

          Cache

          API responses are cached for 12 h. Bookmarks, history and settings never leave your machine.

          Privacy

          OctoLens keeps your bookmarks, recent repositories, notes, preferences, settings and optional token on this device. Repository context and search queries are sent directly to GitHub's API; the optional token is sent only to api.github.com. No OctoLens server, analytics, ads or data sale. Read the privacy policy.
